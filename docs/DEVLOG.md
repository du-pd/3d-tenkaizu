操作フローに沿って「1 モデル → 2 用途とサイズ → 3 出力」の3段。基本設定と `<details>` の詳細設定を分離。
- 出力モード(ペーパー/レーザー)で `[data-mode-section]` の設定群を出し分け。
- 「のりしろ／接続タブ」は両用途の共通設定（レーザーでも接続タブを出す）。
- SVGが主要操作、DXF・印刷は補助。`updateOutputState()` で出力不能/処理中はDLボタンを無効化。
- ログは折り畳み、通常時は `#resultSummary` に結果サマリーだけ表示。印刷注意は印刷ボタン付近。
- `#currentModel` に現在のモデル名、`[data-sample]` に aria-pressed で選択状態。
- スマホは `[data-mobile-panel]`＋タブ(`#tabSettings/#tab3d/#tab2d`, 矢印キー対応)の3構成＋下部操作バー。
- PC幅では 3D:展開図 ≒ 40:60。手動編集(切る/繋ぐ)は3Dの上部。

## 重要な設計判断・注意
- 展開計算は自前実装。数学的正しさ（回転=等長変換、二面角の符号）を最優先。凸辺=山折り。
- 3Dプレビューは Three.js ではなく自前Canvas（CDN不要・単一サイト完結を優先）。
- 印刷は「用紙に合わせる」オフ厳守の警告をUI常時表示。SVGはmm単位、印刷は実寸保証。
- DXFは Illustrator 互換のため フルR12(AC1009) 構成（LTYPE/LAYER/STYLE + 空BLOCKS + EXTMIN/MAX）。
- のりしろ干渉解決は corner-clip ではなく「短縮→削除」方式（glueしやすい台形を保つ・外部依存なし）。

## 実装済み機能（まとめ）
- **入力**: STL(バイナリ/ASCII自動判定)・OBJ。頂点溶接、穴/非多様体の検出と警告、破損検出。
- **展開**: 平面マージ → 全域木(平坦辺優先) → 2D展開 → 重なりで自動分割。等長性はテスト済み。
- **のりしろ**: 付け根=SCORE / 外周=CUT。同一パーツ本体・他のりしろとの干渉を短縮/削除で解消（件数ログ）。
  クリアランス(kerf)設定（既定0.3mm）。
- **出力**:
  - ペーパークラフトSVG（山谷線・のりしろ・パーツ/辺番号）
  - レーザーSVG（CUT/SCORE/ENGRAVE をレイヤー・色分離、Inkscapeレイヤー付き）
  - DXF（フルR12、レイヤーCUT/SCORE、mm、Y上向き）
  - 折り線の実線/破線（破線は SVG/DXF とも実線分に分割、破線長・間隔mm指定）
  - レーザー時、山折り=一点鎖線 / 谷折り=破線 でパターンを変えて区別（付け根=破線）。凡例も連動
- **用紙/レイアウト**: A4 / A3 / カスタム(既定300×600)。複数パーツは複数ページに自動分割。
  実寸出力(最大寸法mm指定)、印刷範囲への自動フィット(縮小)。
- **印刷**: 複数ページを各シートに分割。@pageを選択用紙に合わせ実寸で印刷。
- **プレビュー**: 3D(回転/ズーム、折れ=緑赤青の辺色分け)、2D展開図(モード連動の凡例)。スマホ対応。
- **その他**: 大モデルの三角形数警告＋処理時間ログ。アクセシビリティ(label/aria-live/canvas代替)。

## 既知の制限
- 平面マージの外周抽出は単純ループ（穴なし面）前提。穴あき面はマージせず個別に残す。
- 重なり回避は貪欲法。最適なパーツ数にはならない（シェルフパッキングも単純）。
- 単一パーツが用紙を超える場合は**ポスター分割**で対応（重ね代＋トンボ＋タイル位置ラベル付き）。ただし DXF はタイル分割せず全体を1回だけ出力（レーザーのベッド超えは非対応）。
- 大モデルは同期処理（Web Worker未実装）。減面処理は未実装。
